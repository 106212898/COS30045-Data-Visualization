About the project

Why WattWise exists

WattWise is a small demonstration website built for a university web development assignment, exploring how Australian households use energy through their appliances — with televisions as the worked example.

Purpose & scope

This site was built to demonstrate core web development concepts: a shared navigation structure across multiple pages, external CSS styling, and JavaScript-driven interactivity through the FAQ accordion on the home page.

All appliance and energy figures shown across the site are placeholder values created for demonstration purposes, in the style of real Australian household energy data.

Method

How it was built

Three HTML pages sharing a single external stylesheet and script file.

Semantic HTML, a consistent colour system drawn from the power logo, and accessible interactive components.
